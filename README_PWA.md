# DTC.xlsx PWA · v14.4.1 Excel UI

The PWA is presented as an Excel-style workbook named `DTC.xlsx`.

Sheets: `국장`, `국장ETF`, `미장`, `미장ETF`, `Quiz`.

The market grid uses daily/weekly SuperTrend(14,2) opinion data produced by the existing v14.4 scanner. The formula bar doubles as a global stock finder. Type a stock name or ticker and press Enter to jump to the best match across all sheets.

The Quiz presents one 90-session problem at a time with five choices. Only candles and SuperTrend(14,2) are shown.
